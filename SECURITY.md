# Security Policy

## Supported Versions

Security fixes are applied to the current `main` release line and the latest published production release.

## Reporting a Vulnerability

Please do not disclose security vulnerabilities in public issues.

Use GitHub's private vulnerability reporting/security advisory mechanism for this repository. Include:

- affected version or commit
- affected component/file
- reproduction steps or proof of concept
- security impact
- any known mitigations

If the report involves credentials, tokens, keys, or other secrets, do not include the secret value in the report. State what kind of credential is affected and where it was exposed.

We will triage reports, protect sensitive information, and provide remediation or mitigation guidance as appropriate.
