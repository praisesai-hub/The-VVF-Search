# AI/ML Model Audit Sources

This audit uses the following official sources as the evaluation baseline for model transparency and LiteRT runtime contracts.

| Source | Audit relevance |
|---|---|

| https://developers.google.com/edge/litert/conversion/tensorflow/metadata | LiteRT metadata describes model, input, output, preprocessing, post-processing, and associated-file contracts. |
